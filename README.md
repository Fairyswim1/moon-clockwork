# 달빛 시계공방

중1 최대공약수·최소공배수 단원의 8개 조작 퍼즐입니다. 막대의 공통 부품을 가장 길게 만들고, 주기적으로 켜지는 등불이 처음 다시 만나는 시간을 맞춥니다.

## 실행

Node.js 22 이상. 외부 패키지 설치 없이 `npm start` 후 http://127.0.0.1:4173 을 엽니다. `npm test`는 독립 열거 풀이 검증, `npm run build`는 정적 `dist/` 생성입니다.

## 조작과 학습

- 슬라이더, 숫자 입력, ± 버튼으로 길이 또는 시간을 조절합니다. 조절 자체에는 페널티가 없습니다.
- 실행 버튼으로 제작/점등을 확인합니다. 공통이지만 최댓값/최솟값이 아닌 경우 별도 피드백을 줍니다.
- 소인수분해 노트에서 지수를 비교할 수 있고 성공 후 선택한 지수와 결과를 확인합니다.
- 8개 의뢰는 자유롭게 선택할 수 있습니다. 모두 성공하면 축제가 열립니다. 최고 별은 브라우저에 저장됩니다.
- 별은 실행 오답 0회 3개, 1~2회 2개, 3회 이상 1개입니다. 재도전해 개선할 수 있습니다.

`sources.json`은 개념의 교과서 출처, `design.json`은 후보 비교와 학습 설계, `assets/prompts.json`은 내장 이미지 도구의 생성 프롬프트입니다. 교과서 원문 및 PDF는 포함하지 않습니다.

수학 엔진은 전수 약수 열거와 배수 탐색으로 독립 검증합니다. 실제 브라우저 결과는 `evidence/browser-review.json`에 기록합니다. 학생 대상 학습 효과나 모든 보조기기 접근성을 검증한 것은 아닙니다.
